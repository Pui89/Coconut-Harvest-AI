1. Choose images

Choose downloaded image files. Images stay in your browser; nothing is sent to a server.

No images loaded.

2. Annotate

Drag a rectangle around each visible coconut. Boxes are saved per image. Select a box and press Delete to remove it. Use ←/→ to change images.

Only label coconuts that are actually visible. Do not label guessed or fully hidden fruit. Review downloaded image licences and provenance separately.

3. Export

Save the JSON file. Then use tools/convert_annotations_to_yolo.py to create YOLO label files locally.
