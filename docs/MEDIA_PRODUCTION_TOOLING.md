# Media Production Tooling — AbsentMotion (Candidate)

**Project:** Coconut Harvest AI  
**Status:** Candidate tool only — not installed, integrated, tested, or approved for production use.

## Intended use

Create short explainers for the four coconut maturity classes, harvesting workflow concepts, and clearly labeled simulated demonstrations.

AbsentMotion may be evaluated as an optional open-source tool for:
- Motion graphics and keyframe-based product explainers
- Short product-introduction videos and animated walkthroughs
- Captions, titles, transitions, and social/web media assets
- Exporting review copies for the PUI89 website and presentations

Project links:
- Source repository: https://github.com/Comett1225/AbsentMotion
- Project page: https://comett1225.github.io/AbsentMotion/

## Verification and acceptance gates

The upstream GitHub repository currently identifies the project license as **GNU GPL-3.0**. This is a repository metadata check, not a full legal review. Before adoption, verify the current license file, bundled assets, fonts, codecs, model weights, and all third-party notices.

Feature availability, supported operating systems, import compatibility, offline behavior, export formats, and performance must be tested against the exact release and target device. Do not treat promotional feature descriptions as verified PUI89 test results.

Acceptance checklist:
1. Review the current source, release history, dependencies, and provenance.
2. Confirm the intended platform and hardware compatibility before any download or installation.
3. Test a small, non-sensitive sample project; record the application version, device, settings, and export result.
4. Check output quality, audio/video codec compatibility, subtitle rendering, and project-file portability.
5. Review licenses and usage rights for every imported image, video, font, sound, model, and other asset.
6. Keep original editable project files and export settings alongside published media.

## PUI89 safety and evidence rules

- This tool is for **media authoring only**. It is not part of the Shared AI Core, runtime, robot control, perception, or safety architecture.
- Label concept art, animation, and simulation footage as **concept**, **illustrative**, or **simulation** as applicable.
- Never present an animation as a physical prototype, field test, measured result, or validated capability.
- Do not fabricate sensor output, performance metrics, user testimonials, or test evidence.
- Do not include confidential, personal, or operationally sensitive footage without authorization.
- Preserve source attribution and maintain an asset/license record for published media.
