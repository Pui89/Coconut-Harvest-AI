## Evidence rules
- Never use example rows as real data.
- Do not report model metrics unless predictions were generated by actually running the stated model on the stated split.
- Keep test data separate from model/threshold selection.
- Do not claim maturity classification, 3D targeting, field generalisation, cutting safety, or physical robot performance from bounding-box metrics alone.
- Record failed runs and negative results; do not hide them.
