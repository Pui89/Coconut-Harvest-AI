# Local-First Vision-to-Robot Proposal — Retired

**Status: disabled.** The previous image-to-depth detector bridge has been removed from the active application. This repository no longer provides automatic coconut detection or a model-backed RGB-D target proposal.

The existing safety and simulation utilities may still process explicitly supplied example evidence, but that is not image perception. Manual evidence must not be represented as detector output.

No detector framework, checkpoint, automatic inference path or robot execution capability is selected. Any future implementation requires a separate architecture, dependency, licence, security and validation review.

Real robot operation remains out of scope. No report or simulation authorizes actuator commands.
