# PUI89 Product Tiers

This project is one vertical product in the PUI89 AI Robotics platform.

## PUI89 Research

**Audience:** universities, robotics competitions, researchers.

Purpose:
- reproducible experiments;
- open benchmarks;
- simulation and datasets;
- research APIs;
- ablation studies;
- transfer-learning experiments;
- publication-quality evaluation.

Research builds must clearly separate measured results from targets and design concepts.

## PUI89 Professional

**Audience:** farms, plantations, agricultural operators.

Purpose:
- field deployment;
- supervised autonomy;
- mission dashboard;
- maintenance and telemetry;
- model monitoring;
- hardware integration;
- documented safety and failure handling.

Professional releases require evidence from representative field tests before claims are upgraded from prototype to validated.

## PUI89 Enterprise

**Audience:** large corporations, governments, logistics, ports, infrastructure operators.

Purpose:
- fleet management;
- private/on-premise deployment;
- RBAC/MFA;
- signed OTA;
- audit logs;
- API integration;
- SLA/support;
- cybersecurity and supply-chain controls;
- digital twin and asset management.

## Revenue model

Hardware + deployment + maintenance + software subscription + AI/model updates + enterprise integration.

The objective is recurring value per deployed robot, not a one-time hardware sale.

## Shared platform

All three PUI89 verticals should share:
- sensor abstraction;
- perception interfaces;
- 3D world model;
- uncertainty/OOD;
- task planning;
- deterministic safety supervisor;
- ROS 2 integration;
- telemetry;
- MLOps/model registry;
- simulation/digital twin;
- fleet management.
